# Mealie Weekly Leftovers v1.2.0

## Highlights
- Rester7 compatibility with Mealie v3.29.0
- Recipe scaling preserved when creating and editing meals
- Leftovers excluded from bulk and day-level shopping lists
- Legacy Weekly Leftovers metadata supported
- Compatibility retained for Mealie v3.23.1 and v3.24.0

## Validation
- Python and locale checks
- Patch compatibility and application tests
- Patched frontend builds through GitHub Actions

## Important
This is an independent community patch, not an official Mealie release.
Installing or upgrading the patch is a separate operation.
